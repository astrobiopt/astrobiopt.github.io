Template license & credits
===========================

This site is built on top of the "TechKing" Bootstrap/HTML5 template,
used here as the base for the AstroBioLusitanos (ABL) website. The
content, images, pages and features specific to ABL (intro animation,
interactive map, interviews, workshops, team, etc.) were added on top
of this base template.
